# AGENTS.md

Este arquivo descreve o projeto para agentes de IA que forem trabalhar neste repositório.

## Visão geral

O projeto se chama **clone-tabnews-ia**. Segundo o `README.md`, seu objetivo é:

> Implementação do https://tabnews.com.br para o https://curso.dev utilizando agentes de IA

Ou seja, a meta de longo prazo é **clonar o TabNews** (plataforma de notícias e discussões para desenvolvedores, criada por Filipe Deschamps) como projeto de estudo do **curso.dev**, com apoio de agentes de IA no desenvolvimento.

## Stack

- **Next.js** (App Router)
- **React**
- **TypeScript** (modo `strict`, alias `@/*` → raiz do projeto)

## Scripts

```bash

npm run build   # next build

```
